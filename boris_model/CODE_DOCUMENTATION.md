# Документация к коду `boris_model`

## Инструкция пользователя

1. Запустите интерфейс:

   ```bash
   uv run python boris_model/main.py
   ```

2. В верхней части правой панели выберите модели, которые нужно считать:
   `Квазистационарная`, `Усложненная теплопроводность` или обе сразу. Должна
   быть выбрана хотя бы одна модель.

3. Если нужно изменить параметры, используйте левую панель:

   - `Параметры аппаратуры` — геометрия виал, `Kv`, число виал и прочее;
   - `Параметры образца` — `Tc`, безопасный отступ `deltaTc`, высота заполнения,
     концентрация, `Rp`, `Rs`;
   - `Параметры процесса` — диапазоны `Ts_lim` и `Pch`, число точек сетки, шаг
     времени, скорость нагрева и т.д.;
   - `Данные предельного режима` — коэффициенты или экспериментальные точки
     предельной производительности оборудования.

   В открывшемся окне введите новые значения и нажмите `Сохранить`. После
   изменения параметров карты нужно пересчитать.

4. Нажмите `Запустить расчет`. Программа рассчитает выбранные модели по сетке
   `Ts_lim/Pch`; ход расчета показывается прогресс-баром сверху. После расчета
   в правой части окна появится график D. По клику на него открывается
   интерактивное окно Matplotlib с панелью управления.

5. Чтобы построить временные кривые для одной рабочей точки, заполните поля
   `Ts, °C` и `Pch, Torr`, затем нажмите `Получить кривую`. Кнопка работает
   после расчета карт, чтобы выбранные модели и графики соответствовали друг
   другу.

6. В поле `Название образца` задайте имя папки для результата. По умолчанию там
   стоит дата и время запуска.

7. Нажмите `Сохранить данные`. Программа создаст папку с указанным названием
   рядом с `main.py` и сохранит туда CSV, PNG-карты 2x2, отдельные карты,
   `plot_data.pkl`, `timeseries_data.pkl`, `timeseries.png` и GIF
   `vial_combined_model.gif`.

8. Если нужно позже открыть сохраненные графики без пересчета, используйте:

   ```bash
   uv run python boris_model/plot_saved_data.py boris_model/output_data/plot_data.pkl
   ```

## Запуск

```bash
uv run python boris_model/main.py
uv run python boris_model/main.py --cli
uv run python boris_model/plot_saved_data.py boris_model/output_data/plot_data.pkl
```

GUI читает параметры из `boris_model/options.pkl`. Если файла нет, создается
экземпляр `physics.Params` со значениями по умолчанию.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `physics.py` | Константы, параметры `Params`, свойства льда/пара, `Kv`, `Rp`, поток сублимации, формулы Tang & Pikal для звездочки. |
| `model_quasi_equilibrium.py` | Быстрая квазистационарная модель с балансом тепла и массы. |
| `model_conduction.py` | Усложненная модель с 1D-теплопроводностью в слое льда и генерацией GIF. |
| `main.py` | Tkinter GUI, пакетный CLI, расчет сеток, графики, CSV/PKL/PNG вывод. |
| `plot_saved_data.py` | Просмотр сохраненных `plot_data.pkl` и `timeseries_data.pkl` без повторного расчета. |

## Поток расчета

1. `load_options()` загружает `options.pkl` или создает дефолтный `Params`.
2. `build_grid()` строит сетку `Ts_lim` и `Pch`.
3. `calculate_all()` прогоняет выбранные модели по всем точкам сетки.
4. `run_grid()` вызывает модель для каждой пары `Ts_lim/Pch` и собирает:
   `t_dry`, `Tp_max`, `rate`, `Ts_C`, `Pch`.
5. `plot_maps()` сохраняет карты A/B/C/D в формате 2x2 и отдельные панели.
6. `save_csv()` и `save_plot_data()` сохраняют табличные данные и pkl для повторной отрисовки.

## GUI

Верхняя часть правой панели содержит чекбоксы моделей:

- `quasi_equilibrium` — квазистационарная модель;
- `conduction` — модель с теплопроводностью.

Перед расчетом проверяется, что выбрана хотя бы одна модель. Прогресс-бар
считается как `обсчитанные точки / все точки` по выбранным моделям.

Кнопка `Получить кривую` требует уже рассчитанных карт для выбранных моделей:
это защищает интерфейс от неявного смешивания старых карт и новой временной
кривой.

## Графики

- A: время сушки по сетке `Ts_lim/Pch`, плюс линии `max(Tp)=Tc` и
  `max(Tp)=Tc-deltaTc`.
- B: максимум температуры продукта по сетке.
- C: средняя скорость сублимации; цветовая шкала показывает скорость.
- D: рабочая область, линии температурных ограничений, экспериментальная
  линия предельного режима и звезда Tang & Pikal.

Звезда Tang & Pikal считается так:

```text
Tp = Tc - deltaTc
Pch = 0.29 * 10^(0.019 * Tp)
Ts = Tp + 1/Av * dQ/dt * (1/Kv + l_ice/kI)
```

После расчета `Pch` и `Ts` ее координата по оси скорости берется интерполяцией
по рассчитанной карте.

## Добавление параметров

1. Добавить поле в `physics.Params`.
2. Добавить имя поля в нужную группу `PARAM_GROUPS` в `main.py`.
3. Если параметр нужен в сохраненных графиках, ничего дополнительно делать не
   нужно: `params_to_dict()` сохраняет все поля `Params`.

## Добавление новой модели

1. Реализовать функцию вида `run(Ts_lim_K, Pch_torr, p)`.
2. Вернуть словарь с ключами, совместимыми с текущими моделями:
   `t_dry_h`, `Tp_max_K`, `rate_mean_g_h`, а для временных графиков также
   `t_h`, `Tmin_K`, `Tmax_K`, `Ts_K`, `grad_min`, `grad_max`.
3. Добавить функцию в `MODELS` и человекочитаемое имя в `MODEL_LABELS`.
