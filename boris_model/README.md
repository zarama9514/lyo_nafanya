# Модель первичной сушки в лиофилизаторе (ветка `boris_model`)

Моделирование первичной сушки раствора одного вещества в воде **двумя способами**
(отдельные модули) + управляющий модуль с сеткой и 2.5D-графиками. Реализация по
ТЗ (`Nafanya.txt`) и презентации «Разработка модели первичной сушки».

## Структура

| Файл | Назначение |
|---|---|
| `physics.py` | Общая физика и параметры (`Params`): `Pice(T)`, `ΔHs(T)`, `k_ice(T)`, `cp_ice(T)`, `Kv(Pch)`, `Rp(l)=R0+A1·l`, баланс воды по концентрации, рампа полки. Всё в СИ внутри. |
| `model_quasi_equilibrium.py` | **Модуль 1.5** — квазиравновесие: на каждом шаге баланс «тепло полки = сублимация», `Tb` и `Ti` связаны линейным градиентом по столбу льда. |
| `model_conduction.py` | **Модуль 1.4** — нестационарная 1-D теплопроводность в столбе льда (неявная схема, прогонка), ГУ: нагреватель с сопротивлением `Kv` (z=0) и охлаждение сублимацией на фронте (z=L−l). Авто-дробление интервала в конце сушки. |
| `main.py` | «Модуль управления»: сетка (Ts_lim, Pch), прогон ОБОИХ модулей, временные графики (1.3.1–1.3.3) и 2.5D-карты (1.3.4 A/B/C/D), CSV. |
| `ideas.md` | Журнал предложений по усилению модели/программы. |

## Запуск
```bash
uv run python main.py              # сетка, временные графики и 2.5D-карты
uv run python model_conduction.py  # GIF температурной карты в виале
```

### Анимация температурной карты (`make_temperature_gif`)
Функция в `model_conduction.py` строит GIF температурного поля по высоте виалы
(расчёт нестационарной теплопроводности): прямоугольник 100×400 px без рамок,
низ = дно виалы (тёплое), верх = фронт сублимации / сухой кейк (холодное),
сине-красная гамма (синий — холод, красный — тепло), фиксированная шкала.
По умолчанию 10 fps × 20 с = 200 кадров. Файл `vial_temperature.gif`.
Выход: `timeseries.png` (Tmin/Tmax продукта, градиент, Ts от времени),
`maps_quasi_equilibrium.png`, `maps_conduction.png` (карты A/B/C/D),
`grid_*.csv` (сводка по сетке).

## Процесс (ТЗ 1.1)
Старт: продукт = полка = `Tfreeze`, давление `Pch` установилось. Полка греется со
скоростью `ramp` до `Ts_lim`, затем держится. Тепло идёт снизу через дно (`Kv`) и
сквозь столб льда (`k_ice`) к фронту; на фронте лёд сублимирует
(`dm/dt = Ap·(Pice(Ti)−Pch)/(Rp+Rs)`), унося тепло `ΔHs·dm/dt`; сухой кейк растёт
(`l`), `Rp = R0+A1·l`. Стоп при остатке воды < `end_frac` (5%). Задача 1-D,
фронты плоские.

## Графики 2.5D (1.3.4)
- **A** — время сушки [цвет] от `Ts_lim` [x] и `Pch` [y];
- **B** — макс. температура продукта [цвет] от тех же осей + изолиния `Tc`;
- **C** — ср. скорость сублимации [y] от `Pch` [x], семейство по `Ts` [цвет];
- **D** — то же + граница `max(Tp)=Tc` (область допустимого — ниже-левее).

## Параметры по умолчанию (литературные)
Виала 10cc tubing (Tang & Pikal 2004, Табл. II): `Ap=3.80`, `Av=4.71` см²,
`Kc=2.64e-4`, `Kd=3.64`; `L=1` см; `cs=5%`; `Tc=−32 °C` (сахароза); `Rp=R0+A1·l`
с `R0=0.5`, `A1=2.5` (Torr·см²·ч/г); `Rs=0.2`; `Tfreeze=−40 °C`; рампа 1 K/мин;
`dt=0.01` ч. Всё меняется в `Params` (`physics.py`).

## Замечания по физике (диагностика)
Продукт на **десятки градусов холоднее полки** (депрессия `Ts−Tp` ≈ 22…46 °C из-за
сублимационного охлаждения). Для сахарозы (`Tc=−32 °C`) граница коллапса проходит
около `Ts≈−10 °C` при низком `Pch`; поэтому сетка по умолчанию охватывает холодную
зону, чтобы граница `max(Tp)=Tc` была видна на картах B/D. Оба модуля совпадают по
времени сушки и `Tp` в пределах <1% (взаимная валидация).
